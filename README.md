# Пока не наступит рассвет

Интерактивное чтение саги «Сумерки» на монгольском языке.

Главы 1–5: 282 последовательных эпизода, три уровня текста, встроенный
словарь и грамматический разбор, 180 итоговых задания, 45 иллюстрации.
846 аудиозаписей: отрывки и отдельные
предложения, скорость 1× и 0,75×. Аудиозаписи загружаются по мере чтения.

Продвинутый уровень содержит полный текст пяти глав из предоставленного
источника с отдельным журналом языковых исправлений. Начальный и средний
уровни сокращены с сохранением основных событий, причин и реакций героев.
Все 282 эпизода сопоставлены по уровням; найденные смысловые расхождения
исправлены вместе со словарём, пояснениями и соответствующим аудио.

Прогресс и личные слова каждой главы сохраняются отдельно в браузере.
Для переноса между устройствами используйте экспорт и импорт в тренажёре.

Статическая версия без сборки. GitHub Pages: ветка main, корень репозитория.
Исходное литературное произведение — Стефани Майер, «Сумерки».
