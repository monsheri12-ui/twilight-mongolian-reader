# Пока не наступит рассвет

Интерактивное чтение саги «Сумерки» на монгольском языке.

Первая глава: 73 последовательных эпизода, три уровня текста, встроенный
словарь и грамматический разбор, 36 итоговых заданий, 10 иллюстраций.
219 записей синтетическим голосом Microsoft Yesui: отрывки и отдельные
предложения, скорость 1× и 0,75×. Аудиозаписи загружаются по мере чтения.

Прогресс и личные слова сохраняются в браузере. Для переноса между
устройствами используйте экспорт и импорт в тренажёре.

Статическая версия без сборки. GitHub Pages: ветка main, корень репозитория.
Исходное литературное произведение — Стефани Майер, «Сумерки».
