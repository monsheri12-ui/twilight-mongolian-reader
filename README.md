# Пока не наступит рассвет

Интерактивное чтение саги «Сумерки» на монгольском языке.

Главы 1–2: 137 последовательных эпизодов, три уровня текста, встроенный
словарь и грамматический разбор, 72 итоговых задания, 16 иллюстраций.
411 записей синтетическим голосом Microsoft Yesui: отрывки и отдельные
предложения, скорость 1× и 0,75×. Аудиозаписи загружаются по мере чтения.

Прогресс и личные слова каждой главы сохраняются отдельно в браузере.
Для переноса между устройствами используйте экспорт и импорт в тренажёре.

Статическая версия без сборки. GitHub Pages: ветка main, корень репозитория.
Исходное литературное произведение — Стефани Майер, «Сумерки».
