# Пока не наступит рассвет

Пока не наступит рассвет · Вся книга

Tilda: https://foxsaywawa.tilda.ws/twilight
GitHub Pages: https://monsheri12-ui.github.io/twilight-mongolian-reader/
Репозиторий: https://github.com/monsheri12-ui/twilight-mongolian-reader

Предисловие, 24 главы и эпилог: 1148 эпизодов, три уровня,
контекстные карточки слов и цветной грамматический разбор,
912 заданий, 162 иллюстраций и 3444 аудиозаписей голосом Yesui.

Продвинутый уровень сохраняет полный монгольский текст предоставленного
источника после ограниченных языковых исправлений с отдельными журналами.
Начальная и средняя версии упрощены с сохранением событий, участников,
причин, отрицаний, предположений и эмоциональных реакций. Неясные чтения
источника не заменены внешним литературным каноном.

Слушать можно целый эпизод или отдельные предложения, скорость 1×/0,75×.
Все записи проверены на декодирование, непустой звук, соответствие тексту
и границы временных меток. Проверка произношения носителем не проводилась.
На сайте при выборе главы загружаются только её текст и аудиоуказатель;
звуковые файлы загружаются по мере чтения.

Для работы без сети распакуйте ZIP и откройте index.html, сохранив файлы
рядом с ним. Отдельный файл «Пока-не-наступит-рассвет.html» содержит все
изображения и записи внутри. Из-за объёма он удобнее на компьютере.

Прогресс каждой главы сохраняется отдельно в браузере. Для переноса
выберите главу, скачайте её файл прогресса и загрузите в той же главе
на другом устройстве. Локальная и публичная версии имеют отдельные
браузерные хранилища. Формат прежних сохранений не изменён.

Спорные значения и конструкции сопоставлялись с Кульманом и Церенпил,
словарём Bawden и монгольскими словарями. Точный охват и ограничения
проверок по главам находятся в reports. Проверка носителем не заявляется.
