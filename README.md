# Пока не наступит рассвет

Интерактивное чтение саги «Сумерки» на монгольском языке.

Главы 1–13: 684 последовательных эпизода, три уровня текста,
контекстный словарь и грамматический разбор, 468 итоговых заданий,
111 иллюстраций и 2052 аудиозаписи голосом Yesui.
Можно слушать отрывок или отдельные предложения на скорости 1× и 0,75×.
Аудиозаписи загружаются по мере чтения.

Продвинутый уровень содержит полный текст соответствующих тринадцати глав
из предоставленного источника с отдельными журналами ограниченных языковых
исправлений. Начальная и средняя версии упрощены с сохранением событий,
действующих лиц, причин, отрицаний, предположений и эмоциональных реакций.
Неясные чтения источника не заменены внешним литературным каноном.

В главах 8–13 добавлены 302 эпизода и 906 аудиофрагментов. Все шесть глав
прошли независимое сопоставление версий и контекстную проверку карточек.
Границы словарной и грамматической проверки зафиксированы в локальных
отчётах; отдельная словарная проверка каждой продуктивной формы и проверка
носителем языка не заявляются.

Чтение, слова и результаты заданий сохраняются отдельно для каждой главы.
Для переноса между устройствами используйте экспорт и импорт в тренажёре.

Статическая версия без сборки. GitHub Pages: ветка main, корень репозитория.
Исходное литературное произведение — Стефани Майер, «Сумерки».
