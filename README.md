# Пока не наступит рассвет

Интерактивное чтение саги «Сумерки» на монгольском языке.

Главы 1–7: 382 последовательных эпизода, три уровня текста, встроенный
словарь и грамматический разбор, 252 итоговых задания, 77 иллюстраций.
1146 аудиозаписей: отрывки и отдельные предложения,
скорость 1× и 0,75×. Аудиозаписи загружаются по мере чтения.

Продвинутый уровень содержит полный текст семи глав из предоставленного
источника с отдельным журналом языковых исправлений. Начальный и средний
уровни сокращены с сохранением событий, причин и реакций героев.
В седьмой главе 53 эпизода; все версии сопоставлены по смыслу.
Неоднозначные чтения источника не заменены внешним литературным каноном.

Прогресс и личные слова каждой главы сохраняются отдельно в браузере.
Для переноса между устройствами используйте экспорт и импорт в тренажёре.

Статическая версия без сборки. GitHub Pages: ветка main, корень репозитория.
Исходное литературное произведение — Стефани Майер, «Сумерки».
