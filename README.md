Сага «Сумерки» · Стефани Майер · Читаем на монгольском

Предисловие, 24 главы и эпилог. Три уровня текста, перевод на русский,
карточки слов, цветной разбор грамматики, аудио и задания.

Сайт: https://foxsaywawa.tilda.ws/twilight

Для работы без сети распакуйте архив и откройте index.html.
Оставьте остальные файлы рядом с ним. Отдельный HTML-файл всей книги
содержит иллюстрации и аудио внутри и удобнее для компьютера.

Нажмите на слово в отрывке, чтобы открыть карточку и добавить слово
для повторения. Переключатели главы и уровня находятся над текстом.
Слушать можно весь отрывок или отдельные предложения; скорость 1×/0,75×.

Прогресс сохраняется отдельно для каждой главы в этом браузере.
Для переноса используйте «Сохранить или перенести прогресс» и выберите
ту же главу при загрузке сохранения на другом устройстве.
